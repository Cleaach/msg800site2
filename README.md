# Basic Stochastic Processes — lecture notes

This is a lightweight static study site containing a searchable, page-by-page transcription of the uploaded lecture notes. The published bundle is text-only: the source scans are not required to read or navigate the notes.

## Local preview

Run python3 -m http.server 4173 --directory site from the parent directory and open http://localhost:4173.

The site is intentionally dependency-free: no build step, framework, or external font download is required. Math is styled with system math fonts such as STIX Two Math and Cambria Math when available, with a serif fallback.
